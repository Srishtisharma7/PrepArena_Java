# PrepArena Java — Quiz Application

A Java-based desktop quiz application developed using Java and a graphical user interface.

## Overview

PrepArena Java is an educational quiz application based on an existing Java quiz project. It provides a starting point for exploring desktop application development, GUI design, and object-oriented programming in Java.

## Project Structure

```text
PrepArena_Java/
├── src/

```

## Technologies Used

- Java
- Java Swing and AWT (GUI libraries, subject to source verification)
- Apache Ant / NetBeans project configuration

## Getting Started

### Prerequisites

- Java Development Kit (JDK)
- Apache NetBeans IDE or a compatible Java IDE

### Running the Project

1. Clone or download this repository.
2. Open the project in NetBeans using the existing project configuration.
3. Allow the IDE to resolve the project configuration.
4. Build the project.
5. Run the configured main class.

If the project does not build, verify the JDK configuration and the project's entry point.

## Project Goals

- Explore Java desktop application development.
- Understand how a quiz application can be divided into separate classes.
- Practise GUI programming and project organization.
- Extend the application with independently implemented and tested improvements.
